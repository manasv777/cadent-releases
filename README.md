# Cadent — releases

Download builds of Cadent from the [Releases](https://github.com/manasv777/cadent-releases/releases) tab, or from [cadent.work/download](https://cadent.work/download).

This repository holds release artifacts only. It exists so that downloads have a public, high-bandwidth home; the application source lives elsewhere.

Every release publishes the SHA-256 of its disk image. Verify before opening:

```
shasum -a 256 Cadent.dmg
```

Cadent requires macOS 12 or later on Apple silicon.
